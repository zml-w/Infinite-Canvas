# Infinite-Canvas

`感觉无限画布功能很好用，但是没发现有开源的，所以做了这个简陋的工具，调用comfyui后端来使用。`

**安装：**
 ```sh
 git clone https://github.com/zml-w/Infinite-Canvas
 cd Infinite-Canvas
 npm install
 npm start
   ```



### 请搭配[《ComfyUI-Infinite-Canvas》](https://github.com/zml-w/ComfyUI-Infinite-Canvas)使用
